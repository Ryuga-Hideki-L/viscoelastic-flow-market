# VFM — Viscoelastic Flow Market

**Вязкоупругая модель ликвидности: потоковый механизм ценообразования с марковским вложением памяти для минимизации price impact крупных сделок.**

Исследовательская работа: математическая модель + доказательства + численная симуляция + эскиз смарт-контракта.

## Идея в трёх предложениях

Во всех инвариантных AMM цена — функция *состояния* резервов, поэтому воздействие сделки путь-независимо и полностью перманентно: покупка ⅔ резервов стоит +200% премии, как её ни дроби. VFM делает цену функционалом от *потока* сделок с вязкоупругой памятью Ψ(τ) = κ + γe^(−ρτ): неустранимая (по доказанной теореме невозможности) информационная часть воздействия отделяется от ликвидностной, которая релаксирует и потому амортизируется горизонтом исполнения как Θ(1/T). Требование O(1)-состояния на EVM само выделяет экспоненциальное ядро (марковское вложение) — вся модель умещается в 7 ячеек состояния и ~50k газа на своп.

## Ключевой результат

Кит покупает **20% эмиссии** токена (⅔ резервов пула), капитал пула одинаков:

| | CPMM | VFM (T≈10 ч) | Информационный пол |
|---|---|---|---|
| Средняя премия | 200% | **12%** | 9.7% |
| Сдвиг цены после сделки | ×9.0 | ×1.29 | ×1.246 |

Круговые манипуляции (накачка/сброс) строго убыточны (доказательство через положительную определённость ядра Каца–Мёрдока–Сегё + численная проверка: PnL от −1% до −28% затрат на всей сетке). Сэндвич внутри эпохи невозможен по построению (единый клиринг). Платёжеспособность — алгебраический инвариант.

## Честные ограничения

Модель не отменяет цену немедленности (теорема невозможности): мгновенное исполнение дорого и здесь — VFM монетизирует терпение. Главная уязвимость — медленный фронт-раннинг публичных потоков (квантифицирован: 49% → 7% издержек жертвы с ростом её горизонта; смягчения: шифрование заявок, быстрая релаксация). Строгая теорема об убыточности манипуляций доказана в линеаризованном режиме, для точного — проверена численно. Подробно — §13 статьи.
